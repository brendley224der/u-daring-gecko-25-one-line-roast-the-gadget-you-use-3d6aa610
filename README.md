One original line roasting the gadget used every day — the laptop whose fan treats a spreadsheet like an emergency — written by a small deterministic Python program for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty.

## Run it

```sh
python3 main.py
```

The program writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Pure standard library, no network, deterministic: the same bytes on every run.
